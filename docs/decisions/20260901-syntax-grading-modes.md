# 採点ルールの拡張（任意のまとまり）と通常/MAXモードの新設

## 背景

指示書 2026-08-31-srs-grading-modes（塾長承認 2026-08-31・仕様は塾長と往復して確定済み）。

- 「very well」型（副詞が副詞を前置修飾する場合に、塊全体へ前置修飾の下線を引き、
  塊を丸カッコで囲む書き方）が、正解表に無いまとまり＝「余分」として減点されていた
- 品詞（n・v・a・ad・aux）の書き込みは手間が大きく、通常の練習では働きの記入だけを
  求めたい。品詞まで求めるのは新設のMAXモードに限る

## 決定

### 1. 正解表に「任意のまとまり」の区分を追加する（確定仕様1）

まとまりの正解表に `optional`（書いても書かなくても減点しない）を追加した。

- 書かれたら種類を確かめて受理する。**得点（分母・分子）は動かさない**
  （足すと、書いた人と書かない人で分母が変わり点数の意味がぶれるため）
- 書かれなくても「見落とし」にしない（指摘も出さない）
- **種類を誤って書いたら従来どおり誤り**として数える（減点しないのは正しい流儀だけ）
- 正解表示（第一解）には含めない
- 同じ範囲に必須と任意の行が重なるとき（例: very well の必須の（ ）＋任意の下線）は、
  **種類の合う行 → 必須の行 → 任意の行**の順で対応づける。範囲だけで先着順に対応づけると、
  （ ）が任意の下線の行に吸われて誤り扱いになるため

### 2. 同型箇所の登録はコード側の表で持つ

模範分析集 第7講の35文を全数調査（副詞が隣り合う箇所を機械抽出→1件ずつ判定）し、
同型3文に任意のまとまりを登録した。

| 文 | 塊 | 登録した任意のまとまり |
|---|---|---|
| P3-S1 | ever more | 下線・（ ）とも任意 |
| P4-S4 | so much | 下線のみ任意（（ ）は塾長の正解表に必須であるため） |
| P8-S2 | not simply | 下線・（ ）とも任意 |

除外2件: P4-S6「most commercially」（most は commercially successful 全体に掛かる読みが
自然で、副詞が副詞を修飾する型とは言えない）／P6-S3「up less」（made up の up は
句動詞の一部で、less との修飾関係が無い）。

登録先は生成ファイル（private/syntax-problems）ではなく**読み込み側のコードの表**。
生成ファイルは取り込み直し（data/sync-syntax-problems.mjs）で作り直されるため、
手で書き足すと消える。

### 3. 採点に通常/MAXモードを新設する（確定仕様2・3）

- **通常（既定）**: 品詞の書き込みを求めない。未記入は素通し（減点も指摘もしない）。
  書いた場合は確かめて指摘だけ返す（得点に入れない）。
  **例外: 前置詞・接続詞の専用記号（P・Po・▷・＋）は働きの欄の値なので、
  通常でも従来どおり採点される**（品詞の欄を素通しにするだけで自然に成り立つ。
  正解表の品詞の欄に前置詞・接続詞の値が無いことは実データで確認済み）
- **MAX**: 従来どおり品詞まで採点する
- モードの置き場所は**画面の切替**（既定=通常・秘書の推奨案どおり）。生徒設定としての
  永続化は今回は不要のため見送り。採点後に切り替えると、その場で採点し直す

### 4. 筆順登録（お手本登録）の品詞5種を必須から任意へ（確定仕様4）

必須は括弧8種＋働き7種の**15種**（従来20種）。品詞の英字 n・v・a・ad・aux は
任意の一覧へ移し、品詞まで書きたい人だけ「お手本登録」から追加できる。
品詞のお手本が1つも無くても登録が「完了」になることをテストで固定した
（期待の一覧は定数を参照せず手書き＝教訓 benchmark-self-reference）。

## 影響

- 共有部品 `src/lib/reading/syntax.ts`（採点ロジック）に触れるため、
  本番反映は原則どおり反映前承認（決定記録 20260827-scoped-push-exception の
  承認省略は適用しない）
- 読解1文画面（構文を分析する）の採点・AI判定は今回のモードの対象外（従来どおり）
