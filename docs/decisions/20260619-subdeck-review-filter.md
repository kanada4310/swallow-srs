# フィルタサブデッキは復習もタグで絞る（設計転換）

## 背景
当初は「新規カードのみフィルタ・復習はルート親デッキ全体から」という設計だった。しかしサブデッキで学習すると、無関係な親デッキの復習が全部出てきて生徒の負担になった。

## 決定
`getStudyCardsOffline` で**新規・復習の両方をタグで絞る**。デッキ一覧の「復習 N」表示（元々タグ絞り済み）とも一致する。全件まとめて復習したいときはフィルタの無い親（ルート）デッキを学習する。

## 結果
CLAUDE.md のフィルタデッキ節を更新。将来「サブデッキでも全部復習したい」要望が出たらデッキ設定で切替式にできる。
