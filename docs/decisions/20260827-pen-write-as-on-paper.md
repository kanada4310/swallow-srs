# 紙のとおりに書けるようにする3点（カッコの下の働き・お手本の持ち主・候補の置き場所）

## 背景

塾長がタブレットとペンで実機確認したところ、**書きたいように書けない箇所が3つ**見つかった
（指示書 2026-08-27-srs-pen-write-as-on-paper）。いずれも「紙と同じように書ける」という
ペン方式の前提を崩していた。とくに2つ目は、同じ日に確定した検収の決定3・4
（C や S、前置詞の後の Po は開き括弧の下に書く）が**アプリでは書けない**ことを意味していた。

1. **候補（迷ったときの選択肢）の枠が、書きたい場所に被る**
   位置が「書いた線の58画素上」に固定で、単語の枠も欄の種別も画面の端も見ていなかった。
2. **開き括弧の下に働きを書けない**
   機能自体は 2026-08-26 に入っていたが、発動条件が「その開き括弧が**閉じ済み**であること」。
   開き括弧はまず閉じ待ちに入り、閉じ括弧が来て初めてまとまりになる。
   塾長の書き順（開いてすぐ下に働きを書く）ではこの機能が一度も発動しない。
3. **お手本が、利用者ではなく端末に紐づいていた**
   完了の印は利用者ごと、お手本データ本体は端末ごとの固定の鍵1本。
   同じ端末を別のアカウントで使うと「登録済み」と誤判定され、
   **他人の筆跡のまま完了の印が付き、本人は一度も登録を促されない**。
   塾長の「判別されづらい」の原因はこれと考えられる。

## 決定

### 1. 閉じる前の開始カッコの下にも働きを書ける

閉じ待ちの開き括弧（`PendingOpen`）に働きを持たせ、閉じ括弧が来たときに
そのまとまり（`StudentSpan.role`）へ**引き継ぐ**。同じ位置に閉じ待ちが複数あるときは
最後に書いたもの（＝内側）に付ける。閉じ待ちと閉じ済みが競合したら**閉じ待ちを優先**する
（「開いてすぐ下に書く」書き順では、付けたい相手は直前に書いた開き括弧だから）。
画面にも、閉じ待ちの開始カッコの真下に働き欄の枠を出す（背丈は閉じ済みと同じ）。

### 2. 「まとまり全体の働きか」は単語のすき間で判定する（実装者判断）

もとの条件は「吸着した単語の左端より左に書いたか」だった。しかし実ブラウザで測ると
**カッコの列は12画素ほどしかなく**、そこに書いた線は左どなりの単語のほうが中心に近い。
その結果、吸着が左どなりの単語になり、条件が成立せず**黙って単語の働きに入っていた**。

そこで判定を吸着結果から切り離し、「**その単語の左端より左**」かつ
「**左どなりの単語の右端より右**」＝カッコの列に書いた、で判定する
（狙いのぶれを見込んで前後6画素の余裕。折り返しの行頭など左どなりが無い場合は40画素まで）。
位置条件そのものは残す（緩めると、まとまりの1語目の働きを横取りしてしまう）。

### 3. お手本の保存を利用者ごとにし、判定も本人のお手本で行う

保存の鍵を利用者ごとに分ける。**利用者の付いていない古い保存は読み込まない**
（誰の字か分からないため。安全側＝迷ったら登録し直してもらう）。
あわせて「完了の印」だけで登録済みと判断するのをやめ、
**本人のお手本が必須の種類ぶんそろっているか**で判定する（印は廃止）。
印だけを見ていると、印が本人・中身が他人という食い違いを見逃す。
構文の練習の下部に「お手本の登録: N / 20 種」を出し、画面から確認できるようにした。

### 4. 候補の枠は、書いた場所の反対側へ出す（実装者判断）

- 縦は**書いた段の反対側**（品詞の段に書いたら行の下・働きの段に書いたら行の上）。
  避ける範囲は「書いた線」と「その行の本文」を合わせた帯（本文も隠さない）
- その側が枠に収まらなければ反対側へ折り返す
- **どちらも収まらないとき（1行だけの短い文）は、枠の外（下）へはみ出させる。**
  枠の中へ無理に収めると、必ず書いた場所か本文の上に重なるため。上へ逃がすと
  画面の外に出て押せなくなる恐れがあるので下へ逃がす
- 横は線の中心にそろえたうえで、左右のはみ出しを抑える

決め方は純関数（`chip-place.ts`）に置き、実寸を測って渡すのは共通フック
（`useChipPlacement`）。**書き込み部品と計測ページの両方**が同じ挙動になる。

## やらないこと

記号の約束の変更（○囲みマークを働き欄へ移す・記号台帳の1字化・離れた呼応の波線）、
問題の追加、判別の精度そのものの改良、0.75秒の待ち時間・ゾーン方式・手のひら対策、
消えた線を「一手戻す」で戻せるようにすること（候補が書きたい場所を塞がなくなったので
様子を見てから判断する）。
