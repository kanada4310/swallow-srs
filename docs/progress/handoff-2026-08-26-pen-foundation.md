## 記号台帳・確定版の適用内容

- 品詞: n・v・a・ad・aux（**p 廃止**。練習の正解表・凡例・お手本必須21→20種も更新）
- 働き: S・V・O・C・P・Po・▷・**＋（等位接続詞）**・同格（一覧に追加）
- 深さ: 生徒は書かない。括弧から自動判定→入れ子と同じ色＋控えめな自動ダッシュ印。
  照合用に `dash-notation.ts`（S′ ″ ‴ の相互変換・採点同値・テスト5件）
- ○で囲んだ漢字（仮・真・強調・同格）: 円＋中の字画の組を検出（`classifyExceptionMark`）。
  お手本登録があれば本人の字で判別（機械計測=同一書き手で一発100%）、無くても候補チップから選べる
- [ ]・{ } の開始カッコ真下にまとまり全体の働き（`StudentSpan.role`・矛盾検査も対応）
- 台帳外（?・ダッシュ・Ø・斜線・単語囲み○）: 検出しても反映せず、書き方の案内を出す

## 再生テストの収録（3件）

`src/lib/pen-syntax/replays/` に実機不具合の記録を収録し `replay.test.ts` で再生:
1. ペン無反応（互換タッチの遮断）→ ペン由来として通ることを検証
2. 線ずれ（ズーム中の座標系食い違い）→ 要素相対座標への切り替えを検証＋画面移動の抽出
3. 指スクロール不能 → エリア外の指は待ちなしで通り、書き込み中の手のひらは止まることを検証

今後の実機不具合は「入力の記録」→「再生用をコピー」→ replays/ に保存→テスト1件追加、で再現テストになる。
