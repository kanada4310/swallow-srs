# コロケーション中心デッキは「構文単位SRS＋例文ローテーション」で設計する

## 背景
L2語彙論では、高頻度語は単独の訳語ではなくコロケーション（共起）やフレーズで覚えるのが定着に効く。語義はコロケーションが担う（run=走る/経営する）。

## 決定
- 学習単位は**構文（コア＋スロット）**。SRS は構文単位で間隔管理し、**表示する例文はレビューごとにプールからローテーション**（token頻度＝定着、type頻度＝生産性）
- 語彙は3層で統制: ①語義レベル A1/A2（EVP/GSE 基準・難しい義は除外）②共起語統制（`words.tsv` 照合）③コーパス頻度裏取り（ただし Google Ngrams は弱く補助のみ）
- ノートタイプ「コロケーション構文」に `例文プールJSON` を持たせ、`StudyCard` が毎レビュー1本ランダム表示（`例文プール` フィールドが無い通常ノートは素通り）

## 結果
本番974語・2916ノートを投入。文脈アシスト（日本語の場面リード文）は例文プールを `{en,blank,ja,ctx}` に拡張して表面最上部に表示。コーパス裏取りが弱いのは既知の課題（別コーパス/GSE で強化余地）。
