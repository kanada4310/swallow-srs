セッション終了処理を行ってください。

1. **開発サーバーの停止**: バックグラウンドで動作中の `npm run dev` を停止し、残留 Node プロセスを kill する
   ```bash
   taskkill //F //IM node.exe 2>/dev/null
   ```
2. **キャッシュクリア**: `.next` フォルダを削除する（次回セッションでのフリーズ防止）
   ```bash
   rm -rf .next
   ```
3. 今回のセッションで完了したタスクを `docs/progress.md` に記録
4. `docs/progress.md` の「現在の作業」セクションを以下の形式で更新:
   - Phase: 現在のフェーズ
   - 最終更新: 今日の日付
   - 次にやること: 具体的な次のアクション
5. `docs/progress.md` の「セッション引継ぎメモ」セクションを更新:
   - 今回やったこと（箇条書き）
   - 途中で止まっていること（あれば、具体的にどこまで進んだか）
   - 次のセッションで注意すべきこと（ハマりポイント、未解決の判断事項など）
6. CLAUDE.md の「現在の進捗」セクションを最新の状態に更新
7. ROADMAP.md の該当チェックボックスを更新（完了したものにチェック）
8. 既知の課題があれば `docs/progress.md` の「既知の課題」に追記
9. 未コミットの変更があれば git commit（ファイルを個別に add すること。`git add -A` は使わない）してプッシュ
10. 変更内容の要約を表示
