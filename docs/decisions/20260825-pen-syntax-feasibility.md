# 構文分析のペン入力 — 実現可能性検証の実装設計

作業指示書（統合塾運営エージェント `docs/work-orders/2026-08-25-srs-pen-syntax-feasibility.md`・
塾長承認 2026-08-25・追加費用0円の範囲）を受けた swallow-srs 側の実装設計。
構想の正本は構文添削コーチ構想 v1.3（同リポジトリ `docs/proposals/`）。

## 決めたこと

1. **判別は外部サービスを使わず端末内で完結させる**（0円の制約）。
   形の記号（群A=括弧4種＋下線／群B=○囲み・波線・?・ダッシュ・Ø）は幾何特徴
   （折れの数・閉じ具合・膨らみの向き・円弧と2本線の当てはめ比較）で判別し、
   $P 点群照合（公知アルゴリズムの自前実装 `src/lib/pen-syntax/pdollar.ts`）の結果と混ぜる。
   文字（群C=品詞11種・働き8種）は自由な手書き文字認識ではなく**有限候補への当てはめ**
   （書かれた行で候補を絞る＝上の行なら品詞・下の行なら働き）。
2. **文字は「お手本登録」で本人の字を照合対象に足せる**（localStorage・端末内のみ）。
   内蔵の漢字骨格（名・代・動…）は初期値であり、機械計測でも 助↔動 などの混同が残るため、
   実運用は本人の字の登録を前提にする。
3. **迷った線は候補チップ（2〜3個）でワンタップ確定、それでも拾えなければ一覧（ボタン方式）へ逃がす**
   （構想 v1.1 論点3の確定どおり）。確信の差が小さいときだけチップを出す。
4. **タップ方式は撤去せず切り替えで残す**（第2層・実装者判断）。理由:
   ①ペンの無い端末（スマホ・PC）でも素振りが完結する ②認識に困ったときの最終的な逃げ道
   （逃げ道の滑らかさは合格条件の一部） ③検証段階で方式を比較できる。
5. **○囲み・波線＋?・ダッシュ・Ø は「採点対象外のマーク」として表示だけ保持**（extras）。
   素振りの採点データ（SyntaxAnswer）に対応する置き場が無いため、正誤に数えず画面に出す。
   波線＋?（分からないマーク）の SRS 連携は本実装（別起案）の範囲。
6. **手のひら対策はペン専用方式**。キャンバス上の指・手のひらの接触は線にせず拒否して数える
   （pointerType と接触楕円の大きさで判定・`palm.ts`）。ペンの無い端末向けに
   「指でも書く」モードを用意するが、ペンを使い始めたら指は拒否する。
7. **矛盾検査（0円の床）は採点と独立の純ロジック** `src/lib/reading/syntax-check.ts`。
   ルールブックの言い切りから機械検査できる7項目（Sが2つ／品詞と働きの対応／前置詞と前O の対応／
   〈 〉の直前に名詞がない／{ } の前に O がない／[ ] に役割がない／V がない）を、
   素振りの採点結果の下に表示する。誤検知を避けるため「確実な矛盾」だけを✕にし、残りは△。
8. **共有部品 SyntaxAnnotator には手を入れない**。ペン入力は別部品
   `src/components/pen-syntax/PenSyntaxAnnotator.tsx` とし、本編1文画面（構文に降りる）は不変。
9. **計測は二車線＋二層**。機械計測（種固定の乱数で手書きの揺れを模した線を判別器に通すテスト
   `benchmark.test.ts`）と、実機計測ページ `/reading/syntax/pen-lab`（お題方式の自動集計・
   手のひらカウンタ・結果のコピー欄）。実機のペンでの数字は塾長のタブレットで測る。

## 機械計測の結果（種固定・毎回同じ値）

| 車線 | 一発判別 | 候補タップで確定 | 拾えず |
|---|---|---|---|
| 群A 括弧4種＋下線（n=360） | 90.6% | 8.6% | 0.8% |
| 群B ○・波線・?・ダッシュ・Ø（n=200） | 99.0% | 1.0% | 0% |
| 群C 働き S/V/O/C/M/P/Po/▷（n=320） | 99.1% | 0.9% | 0% |
| 群C 品詞 漢字11種（n=440） | 86.6% | 10.7% | 2.7% |

吸着（単語の前後・範囲への吸着の正誤）: 括弧 100%（n=400）・下線 100%（n=200）・文字 100%（n=200）。
手のひら: 判定ロジック上、ペン使用後の指と大きい接触は全て拒否（機械計測の誤反応 0 件）。

※ これは機械生成の線に対する数字。実機のペンで書いた線の実測は pen-lab ページで行う。
