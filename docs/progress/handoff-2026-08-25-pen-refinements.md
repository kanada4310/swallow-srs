# ハンドオフ 2026-08-25: ペン入力の実機フィードバック6点の改修

指示書: 統合塾運営エージェント `docs/work-orders/2026-08-25-srs-pen-refinements.md`
ADR: `20260825-pen-pos-letters`（品詞の英字略記の採用）

## やったこと（6点それぞれ）

1. **下線が字間で途切れる** → 単語ごとの枠線（border）をやめ、実測した単語の箱（TokenBox）から
   行ごとに1本の連結線を別レイヤーに描く方式に変更（`snap.ts` の `underlineSegments`・折り返し対応・テストあり）
2. **下線が太い** → 3px → 1.5px
3. **カッコの上下位置** → カッコの文字を本文の行の高さ（h-9）の箱に入れて上下中央揃え。
   文字がカッコの縦中央に来る
4. **入れ子カッコの対応** → 深さ別に色分け（`syntax.ts` の `bracketDepths`・開きと閉じが同じ色）。
   配色は色覚多様性対応の Okabe-Ito パレット4色（青 #0072B2・朱 #D55E00・緑 #009E73・赤紫 #CC79A7）
5. **品詞を英字に** → 黄リー教式の英字6種 `n/v/a/ad/aux/p`（字母は模範分析集 形式仕様.md の
   塾長の実書き込みで裏取り。n=名詞・代名詞 / v=動詞・分詞・不定詞 / a=冠詞・形容詞。
   接続詞は字母なし=ルールブックどおり▷と○囲みで表す）。
   採点は漢字の正解表と英字を同値化（`posLetter` 正規化）。矛盾検査も英字対応。
   手書き判別の内蔵お手本を英字で作り直し（機械計測の一発判別 86.6%→98.9%）。
   お手本登録の一覧・既定も英字。**読解1文画面（構文を分析する）は漢字のまま不変**
6. **パームリジェクション** → 下記「6の原因」。「ペンのみ」を既定にし、
   ペンを一度でも見たら画面全体で指・手のひらのタッチを無効化（`usePenScreenGuard`）。
   お手本登録キャンバスにも同じポインタ判定を適用。拒否した接触は preventDefault。
   ペンが反応しない端末の逃げ道=練習ページの「指・マウスでも書く」切替（第2層で実装者判断）

## 6の原因（実機で何が効いていなかったか）

機械上の確認は「判別キャンバスのポインタ判定」だけを通しており、実機ではその外に穴が3つあった:

- **お手本登録のキャンバスが判定を素通し**: ポインタ種別を見ずに全接触を線にしていた。
  実機テストの推奨手順が「先にお手本登録」だったため、手のひらがそのまま線になった（確実な不具合）
- **接触の大きさ(22px)による手のひら判定が実機で働かない**: 実機ブラウザは接触楕円の
  width/height を報告しないことが多く（0 のまま）、大きさでは見分けられない
- **キャンバスの外に載せた手のひらが素通り**: touch-action:none はキャンバス上にしか効かず、
  画面下側に載せた手のひらはページのスクロールやボタン（採点する・下メニュー等）に届いていた

合格条件「手のひらを画面に載せたまま書ける」は、ペンを一度使ったら画面全体で指を無効化する
ガードで満たす（ペンでの操作はそのまま可・ガード中は画面上部に案内チップを表示）。
