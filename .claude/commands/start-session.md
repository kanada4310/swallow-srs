現在の進捗を確認して、次にやるべきことを提案してください。

1. `docs/progress.md` を読んで、完了済み・未完了のタスクを確認
2. `CLAUDE.md` を読んで、プロジェクト方針・進捗を把握
3. `docs/ROADMAP.md` を読んで、ロードマップの状況を確認
4. `git log --oneline -10` で直近の作業履歴を確認
5. `docs/progress.md` の「既知の課題」と「セッション引継ぎメモ」を確認
6. 未コミットの変更がないか `git status` で確認（前セッションの作業残りがないか）
7. 「次にやること」に残っているタスクをリストアップし、**それぞれまだ未完了かユーザーに確認する**（手作業タスクはセッション外で完了している可能性がある）。完了済みのものは progress.md から削除する
8. 以上を踏まえて、次に取り組むべきタスクを1〜3個提案
9. 提案タスクの実装計画を Plan Mode で作成

**注意: コードの変更は行わないこと。計画のみ。**
