# 記憶のいきもの育成は FSRS から導出する純コスメティック層にする

## 背景
育成ゲーム（1ノート＝1株の植物）を導入するにあたり、学習スケジュールに副作用を出さないことが絶対条件。

## 決定
- 成長段階・世話状態（枯れ含む）はすべて既存の `card_states`（FSRS）から**導出するだけ**。学習エンジン・スケジューラには一切書き込まない
- 枯れは**見た目のみ**。復習（=水やり）で FSRS が自然に芽吹き直す（永久ロストなし＝安全弁）
- 品種インプリントだけは新テーブル `user_creature_state`（コスメ情報のみ）
- **クラスランキングは見送り**（順位付けは逆にモチベーションを削ぐ懸念）。やるなら成長率ベース＋オプトアウト前提

## 結果
`src/lib/garden/*` は純ロジック（テスト可能）。現在は `GARDEN_ENABLED=false` で全体停止中（機能は残置・true で再開可）。
