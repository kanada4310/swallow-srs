現在の進捗を確認して、次にやるべきことを提案してください。

1. `docs/progress.md`（索引＋現在地＋最新ハンドオフへのリンク）を読み、「現在の作業」「既知の課題」を把握
2. `docs/progress.md` の「最新ハンドオフ」リンク先（`docs/progress/handoff-*.md`）を読み、直前セッションの引継ぎを把握
3. `docs/decisions.md`（ADR索引）で直近の技術判断を確認。実装に関連する詳細は `docs/decisions/YYYYMMDD-<slug>.md` を個別に開く
4. `CLAUDE.md` でプロジェクト方針・コミュニケーションルール・運用ルールを把握
5. `docs/ROADMAP.md` でロードマップの状況を確認
6. `git log --oneline -10` で直近の作業履歴、`git status` で未コミットの変更（前セッションの残り）を確認
7. 「次にやること」に残っているタスクをリストアップし、**それぞれまだ未完了かユーザーに確認する**（手作業タスクはセッション外で完了している可能性がある）。完了済みは progress.md から削除する
8. 以上を踏まえて、次に取り組むべきタスクを1〜3個提案（CLAUDE.md の報告の型に従い、推奨案を先頭に）
9. 提案タスクの実装計画を Plan Mode で作成

**注意: コードの変更は行わないこと。計画のみ。**
