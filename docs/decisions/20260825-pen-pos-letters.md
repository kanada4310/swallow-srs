# 品詞の書き込みは黄リー教式の英字略記6種（n/v/a/ad/aux/p）に統一する

## 決定

構文の練習（ペン方式・タップ方式とも）とペン判別の計測ページで、品詞の表示・入力・手書き判別を
漢字の品詞名から**英字略記6種**に変更する。

- `n`=名詞・代名詞 / `v`=動詞（分詞・不定詞を含む） / `a`=冠詞・形容詞 / `ad`=副詞 / `aux`=助動詞 / `p`=前置詞
- 接続詞には品詞の字母を書かない（従位接続詞=働きの「▷」、等位接続詞=○囲みで表す。ルールブックどおり）

## 根拠（字母の裏取り）

- 塾長の実機フィードバック（2026-08-25）:「手書きの漢字の認識が弱そうなので、品詞は黄リー教式のアルファベットにしたい」
- 字母は quiz_generator `subjects/英語/模範分析集/形式仕様.md` に転記された**塾長自身の実書き込み**
  （第7講35文）で裏取りした。実データに現れる品詞の字母は n/v/a/ad/aux/p の6種のみで、
  代名詞は n、冠詞・形容詞は a、分詞は機能に応じて v/a/n と書かれている
- ルールブック正本・増補には品詞の英字略記の定義はない（品詞は漢字名、働きが S/V/O/C/P/Po/▷）

## 実装方針

- **アプリ内部の品詞語彙（`POS_OPTIONS`・読解1文画面・構文AI）は漢字名のまま変えない。**
  保存済みの `reading_progress` や AI 判定の語彙を壊さないため
- 構文の練習の採点は、漢字名の正解表と英字を**同値扱いにする正規化**（`posLetter`）で照合する。
  英字は 冠詞/形容詞（a）、動詞/分詞/不定詞（v）、名詞/代名詞（n）を区別しないため、
  その粒度の区別は採点・矛盾検査から自然に消える（塾長の実書き込みと同じ粒度）
- 手書き判別の内蔵お手本・お手本登録も英字で作り直し（機械計測の一発判別 86.6%→98.9%）

## 影響

- 生徒に見える変更は構文の練習ページのみ。読解1文画面「構文を分析する」は従来どおり漢字
- 端末に登録済みの旧漢字お手本（localStorage）は参照されなくなるだけで、害はない
