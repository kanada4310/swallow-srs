# ハンドオフ 2026-08-25（ペン入力の実現可能性検証）

## やったこと

1. **ペンで書く構文分析の試作**を作った。英文の上のキャンバスにペンで書いた線を端末内で判別し
   （外部サービス不使用・0円）、単語位置に吸着させて素振りの解答データに反映する。
   対象は群A（括弧4種＋下線）・群B（○囲み・波線・?・ダッシュ・Ø）・群C（品詞11種・働き8種の
   有限候補への当てはめ＋お手本登録）。迷った線は候補チップでワンタップ確定→一覧への逃げ道。
2. **素振りページ（/reading/syntax）をペン方式既定に置き換え**（タップ方式は切り替えで残置）。
   採点に**矛盾検査**（ルールブックの言い切り7項目・正解表なしで指摘できるもの）を組み込んだ。
3. **計測ページ（/reading/syntax/pen-lab）を新設**。お題方式で判別率・吸着精度・手のひら誤反応を
   二車線（形の記号／文字）別に自動集計し、結果をコピーできる。お手本登録もここ。

## 計測結果（機械生成ストローク・種固定の乱数・毎回同じ値）

- 群A（括弧4種＋下線・n=360）: 一発判別 90.6%／候補タップで確定 8.6%／拾えず 0.8%
- 群B（○・波線・?・ダッシュ・Ø・n=200）: 一発 99.0%／候補 1.0%／拾えず 0%
- 群C 働き（S/V/O/C/M/P/Po/▷・n=320）: 一発 99.1%／候補 0.9%／拾えず 0%
- 群C 品詞（漢字11種の内蔵骨格・n=440）: 一発 86.6%／候補 10.7%／拾えず 2.7%（主な混同: 助→動）
- 吸着: 括弧 100%（n=400）・下線 100%（n=200）・文字 100%（n=200）
- 手のひら: ペン使用後の指・大きい接触は全て拒否（誤反応 0）。ブラウザ実測でも接触2件を拒否

**注意: 上は機械生成の線に対する数字。実機のペンで書いた線の実測は pen-lab で塾長が行う**
（ローカルのマウス描画確認では、幅を潰して書いた波括弧が丸括弧と誤判別される例があった。
境界の書き方は候補チップで救済される設計）。
