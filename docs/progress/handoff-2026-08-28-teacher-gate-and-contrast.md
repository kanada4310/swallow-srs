## 3. 記号の幅

- 台帳（`ledger.ts`）の表示名を半角へ: `( )` `⟨ ⟩`（U+27E8 / U+27E9）`[ ]` `{ }`。
  初回お手本登録の説明文も同じ字にそろえた
- **画面に描く字（`syntax.ts` の `SPAN_TYPES` の `open` / `close`）も同じ字にそろえた**。
  文の上に描かれる括弧はこちらから来ており、台帳だけ直すと同じ画面の中で食い違うため
- **説明の文（`label` / `short`）とAIへ渡す文面は全角のまま**（ルールブックの書き方に合わせている）
- 実ブラウザで、描かれる括弧が `(` `)` `[` `]` になっていることを確認

### 照合・保存に使っていないことの裏取り（指示書の宿題）

記号の見分けは **ID**（`paren-open` など）と**まとまりの種類の名前**（`adv` など）で行っており、
見た目の字は表示にしか使っていない。模範の順序・入力の記録は ID を持ち、
書き込みの保存と採点は種類の名前で行う。見た目の字が入る保存物は構文分析カードの
表示用HTMLだけで、これは保存時に組み上げた文字列なので**過去のカードはそのまま読める**。
テスト（`src/lib/pen-syntax/ledger.test.ts`・2件）で固定した。
