## 途中保存のしくみ（要点）

- 保存の単位は「生徒 × 講」で、中身は1つの JSON。どこで切ったか・大意・組み立て・ヒントの段数が全部入る
- 開いた瞬間は端末の控えから復元し、同時にサーバーと突き合わせて**新しいほうを採る**
- **置き場所がまだ本番に無いあいだは、自動で「この端末にだけ保存」に切り替わる**（入力は失われない）
- 講師の画面は保存された JSON から集計する（別の集計表を持たない）

## 工房からの申し送り3件への対処

1. **ログイン切れで JSON の代わりにログイン画面が返る** → 実物で再現を確認（状態200・中身はHTML）。リダイレクト／中身がHTML／401 の3通りで見分け、「ログインし直してください」の画面に落とす。テスト9件で固定
2. **PWA（先読み）に古い教材が残らないか** → 教材データを**先読みの対象から外した**（`next.config.mjs` の `publicExcludes`）。本番ビルドで先読み一覧99件のうち教材データが**0件**であることを確認。ログイン画面がキャッシュに焼き付く事故も同時に防げる
3. **講名を焼き込まない** → 講の名前・出典・段落数は `index.json` から読むだけ。コードに講名は1つも書いていない
