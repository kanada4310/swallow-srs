# 手書き判定の精度向上: 実書き蓄積（データベース保存）＋見分け強化＋取り違えゼロ側調整

## 背景

指示書 2026-08-31-srs-pen-recognition。方式は 2026-08-31 の文字認識検討会で塾長と全論点合意
（統合塾運営エージェント `docs/proposals/2026-08-31-文字認識検討会記録.md`・確定内容 v1）:
**実書き蓄積（塾の共通お手本集＋本人の蓄積の二段構え・データベース保存）が本命、
似た記号の見分け強化が補強**。外部サービス不使用・費用0円・端末内の即時判定を維持。
合格水準は一発確定85%以上・**取り違え（誤ったまま確定）0.5%以下を最優先**。

## 決めたこと

### 1. 蓄積のテーブル設計（第2層・実装者判断）

`027_pen_stroke_samples.sql` で2表を新設（**本番は未適用**）:

- `pen_stroke_samples`（本人の蓄積）: user_id・symbol・strokes(JSONB)・source・created_at。
  RLS=本人のみ全操作。端末をまたいで引き継げる（従来の localStorage 保存の弱点を解消）
- `pen_shared_samples`（塾の共通お手本集）: **user_id 列を持たない**（検討会確定
  「名前を付けない形」）。読みはログイン者全員・書き込みポリシーなし＝サーバー
  （service role）だけが書く。全員の判定の土台になり、新しい生徒は初日からこの土台で判定される

2表に分けたのは、匿名性を表の構造で担保するため（1表＋ビューでは列の消し忘れで漏れる）。
保存する線は**形を保つ間引き（Douglas-Peucker 方式・1線48点以下）＋座標0.1px丸め・時刻なし**。
等間隔の打ち直しで間引くと、点群照合が「同じ形なのに標本の位相がずれた」ぶんの距離
（実測0.2〜0.3＝候補の差0.12と同程度）を余計に数えるため、形そのものを保つ間引きにした。
上限は本人16件・共通24件/記号、似た線（点群距離0.14未満）は足さない（無限に増やすと照合が遅くなる）。

### 2. 蓄積の関所（検討会確定）

たまるのは**本人が確定し、訂正しなかった線だけ**。実装は PenSyntaxAnnotator が
反映済みの線を鍵つきでため、取り消し（undo）・まとまり削除・マスの値の変更で該当の線を
その場で外し、**採点した時点**で残った線をまとめて送る（候補から選び直した線は source=chip
＝正解確定済みの最良のお手本）。pen-lab のお題正解の線も送る（ラベル確定済みの教師データ）。
既存の端末内お手本は、初回にDB側が空なら自動でDBへ写す（捨てない・指示書の指定）。

### 3. 見分け強化（補強）としきい値

- 括弧: 弦からの離れ具合の分布で「違いの出る部分」を直接見る（へりの平らさ=角括弧・
  幅の狭い真ん中の突き=波括弧のツノ）。重なり地帯（丸めた角括弧と浅い丸括弧）は
  決め打ちせず候補選びへ倒す。**本人のお手本の中では別の括弧が一番近いのに覆すほどの
  差が無いとき（意見割れ）も候補選びへ**
- 文字: 働きに幾何特徴の裏付け（S=前後半で膨らみが逆・▷=閉じて角・＋=直線交差・
  Po=右下の小さな丸）、品詞に画数と横幅（a / ad / aux）
- 波線: 反転3回→2回に緩和＋文字の段でも波線らしければ拾う（候補に挙がる前に弾かれる問題）
- 取り違えゼロ側: 確定に確信の下限（形0.7・文字0.55）。**続け書き時の自動確定にも同じ下限**を
  適用し、下限未満は破棄せず候補を保留列に残して後から選べる
- 着手前（2026-09-01）の挙動は `LEGACY_TUNING` として丸ごと保存し、同じ線で前後比較できる

### 4. 吸着（項目4）

括弧の吸着の境界を「一番近い単語の端」から**単語の中央**へ。同じすき間に重ねて書いた
閉じ括弧や、狭くて次の単語に食い込んだ線が1語ぶん前後する症状（検討会・論点1の症状3）を解消。

## 測り方（検討会・論点6）

3つの数字（一発確定率・取り違え率・候補選び率）を `metrics.ts` が画面の確定ロジックと
同じ規則で数える。合成データ（種固定・**実機の実測ではない**）の前後比較は
`accuracy.test.ts`。実書きデータは pen-lab の「実書きデータをコピー」で採り、
`src/lib/pen-syntax/samples/*.json` に置くと同じ計測が自動で回る（お手本と評価の出どころは
分ける＝教訓 benchmark-self-reference。実書きの蓄積効果は交差評価で測る）。

## 影響

- データベースに2表新設（新しい共有事項候補。適用は塾長の承認後 `npx supabase db push`）
- 練習を開くときに `/api/pen-samples` を読む（オフライン・未適用時は端末内のお手本だけで従来どおり）
- 照合対象が最大で数十件/記号に増えるが、上限と間引きで頭打ち（判定は端末内・即時のまま）
