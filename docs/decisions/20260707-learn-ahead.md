# 学習ステップの待ち時間を learn-ahead（前倒し出題）で解消する

## 背景
新規カードの学習中は学習ステップ（既定 `[1, 10]` 分）を挟む。他に出せるカードが無いと、`StudySession` が待機カウントダウン画面（`WaitingCountdown`）で操作を完全にブロックしていた。生徒から「待たされてストレス」との相談があった。

## 決定
Anki の learn-ahead limit（既定20分）を移植する。main キューが空で、次に予定された学習カードの期限が **learn-ahead しきい値（固定20分）以内なら、待たせずに前倒しで今出す**。しきい値超え（学習ステップを20分より長くした稀なケース）だけ従来どおり待機にフォールバックするので後退はない。

- しきい値は当面**固定20分の定数**（`LEARN_AHEAD_LIMIT_MINUTES`）。非技術者ユーザーに設定を増やさないため設定画面には出さない（将来デッキ設定に露出可能）
- キュー選択を純ロジック `src/lib/srs/session-queue.ts` の `pickFromQueues`（ジェネリック・テスト8件）に切り出し、`StudySession.pickNextCard` から呼ぶ
- **スケジューラ（間隔計算）は不変**。前倒しは最大20分早いだけの表示上の並べ替えで、`card_states` の計算には影響しない

## 結果
待機画面は実質発生しなくなる（学習ステップが20分以内のため）。学習カードが1枚だけ残ると同じカードが連続再提示される（Anki と同じ挙動＝待機よりは良い体験）。反映には Vercel デプロイ＋再ログインが必要。
