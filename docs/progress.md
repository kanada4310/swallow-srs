## 既知の課題
- `scripts/device-preview.mjs` は **Git Bash から実行時 `MSYS_NO_PATHCONV=1` 必須**（`/decks` 等の引数が Windows パスに変換され壊れる）。`--teacher` は偽講師アカウントが講師間共有同期に載るため通常使わない（講師画面は実アカウントで確認）
- Claude Code 内蔵プレビュー（preview_screenshot）はこの環境で恒常的にタイムアウト（a11y snapshot は可）。画面確認は Chrome 連携 or Playwright（device-preview）を使う
- billing側のビルドがWindows環境でOOMになることがある（`--max-old-space-size=4096` で回避）
- LINE端末のIndexedDBに古いユーザーIDがキャッシュされる場合がある（pull APIで対処済み、push APIも同様の対処が必要かもしれない）
- コロケーションパイロットの例文プール: 語彙統制で範囲外語(OOV) ~5-7%（scissors/aloud/vase/cashier/essay 等）。禁止語指定での再生成リペアが未実施
- コロケーション選定のコーパス裏取りは Google Books Ngrams で**弱い**（常用句まで近ゼロを返す）。精度を上げるなら別コーパス（SkELL/Sketch Engine/COCA）か EVP/GSE 段階別リストが必要
- インポート系スクリプトは講師一覧先頭をオーナーにしがち（既定を gaimon.maam に修正済みだが、新規スクリプト作成時は要注意）
- **`(student)`/`(teacher)` グループに共有 layout.tsx が無い** → 新規ページは必ず自前で `<AppLayout>` を巻くこと（巻き忘れるとヘッダー/下ナビが出ない。今回ハマった）
- BottomNav が講師ナビ7項目（庭追加）でやや窮屈。`min-w-0`＋`px-1.5`で収めているが、今後さらに項目を増やすなら再設計（スクロール or まとめメニュー）が必要
- 既存の型エラー `src/lib/db/sync.test.ts(125,48)`（null 非許容）。`tsc --noEmit` では出るが `next build` は通る。本セッションと無関係（要時に別途修正）
- 育成ゲーム: 株グリフは現状**汎用の木1種**のみ（品種別は 10.4）。大規模デッキは `/garden` で MAX_TILES=150 打ち切り（PixiJS化まで）
- **モデルID退役に注意**: コードに `claude-sonnet-4-20250514`(6/15退役)・`claude-3-haiku-20240307`(4/19退役) を直書きしていてAI全機能が500になった。現在は `claude-sonnet-4-6`/`claude-haiku-4-5` に更新済み。新規にClaude呼び出しを足す時は最新IDを使い、退役表は claude-api スキルの models で確認
- **Google Cloud Vision**: 課金プロジェクト数の上限に当たることがある→**既存の課金済みGCPプロジェクトでAPIキーを作成**（キーはどのプロジェクトのものでも可）。`GOOGLE_CLOUD_VISION_API_KEY` 未設定でも Claude Vision に自動フォールバック（位置は近似）
- 画像マスキング一括作成は画像ごとに upload＋AI検出を並列3で投げる（**大量だと Vision/Claude のコスト・レートに注意**）。ビジュアル再編集は**画像差し替え不可**（マスク・設定のみ）。画像キャッシュはURLキーでノート削除時の個別purge未配線（30日TTL任せ）
- **単語帳（定着度ビュー）**: 定着度しきい値（`src/lib/wordbook/mastery.ts` の `MASTERY_THRESHOLDS`=stable7/mastered21・`WEAK_LAPSES`=2）は実データ未調整。古文モードA は語義が 問題 JSON 内にあり sub（補足）に出ない（漢字が出る）＝インライン意味表示は将来強化余地。大規模デッキはタブを開くたび全件走査（重ければキャッシュ/仮想化）
