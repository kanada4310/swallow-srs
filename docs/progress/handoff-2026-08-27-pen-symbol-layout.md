- **下線**: 語の外枠の下端（80）ではなく **ベースライン（67）の1画素下**に引かれ、
  文字にぴったり付く
- **働きの欄**: ○で囲んだ「強」が働き「S」の右に出る（S ○強）

## 塾長にお願いしたいこと（本番反映後）

タブレット＋ペンで本番の「構文の練習」を開き、

1. **カッコを書いたときに、まだ書いていない単語が動かないか**
2. **下線が文字にぴったり付いているか**（q・y の下の棒が突き抜けるのは仕様）
3. **入れ子のカッコが読みにくくないか**（せまいすき間に2つ並んだとき）
4. **○で囲んだ例外の印（仮・真・強・同）が働きの欄に出るか**

窮屈すぎるようなら、カッコの文字をもう一段小さくします。
