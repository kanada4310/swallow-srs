１．文型を認識する
構文分析ではすべての要素を S,V,O,C に還元し、５文型に基づいて考えます。以下では S,V,O,C の意味と対応する品詞、S,V,O,C を用いた５つの文型について説明しています。

Rule  1   すべての文は S,V,O,C を組み合わせて構成されている各要素になりうる品詞は決まっている

要素役割なりうる品詞
S  文の主語名詞
V  文の述語動詞
O  文の目的語名詞
C  文の補語名詞  or  形容詞

●  すべての文は S,V を備えている。
●  V の後ろにどのような要素が必要かは、動詞がどのようなことを意味したいか＝どのような文型を取りたいかによる。
●  O や C は、V の取る文型によって必要であれば考える。
●  C とは主語の性質を説明し、主語 =C と捉えられるものを指す。一方、主語 ≠O である。

  以下はすべて同じ動詞 get を使った文ですが、文型が異なるため意味はすべて異なります。get は５文型すべてを取りうる動詞なのです。

Rule  2   すべての文で、SVOC の構成は右の５文型のいずれかにあてはまる（それ以外の要素の並び方は存在しない）各文型で動詞が示す意味には傾向がある

文型意味の傾向備考
SV  存在・移動・出現
SVC  変化・感覚  S ＝ C
SVO  ——
SVOO  贈与・費用
SVOC  使役  O ＝ C

●  自動詞とは、直後に目的語（ O ）を必要としない動詞のことである。O のない「SV 」「 SVC 」の２つの文型を取る V を自動詞という。
●  他動詞とは、直後に目的語（ O ）を必要とする動詞のことである。O がある「SVO 」「 SVOO 」「 SVOC 」の３つの文型を取る V を他動詞という。

Rule  3  すべての動詞は５文型のうちいずれかを作る。つまり、どの文型をとるかは動詞によって決まる。
動詞 → 文型 → 文の意味の順で決まる
巻末資料１を参照  ●  構文分析の際は、動詞がとりうる文型の候補を挙げて検討する。
●  動詞が取りうる文型は、主なものは暗記必須。その他出会った動詞は毎回文型を辞書等で調べる習慣をつける。
